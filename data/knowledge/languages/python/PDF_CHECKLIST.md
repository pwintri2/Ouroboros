# Python PDF Checklist

Plaats hier bij voorkeur 1 hoofdbron en maximaal 1 extra bron.

Aanbevolen type bronnen:

* officiële Python tutorial of officiële Python documentatie
* compacte gids over file I/O, scripting of best practices

Vermijd:

* extreem grote encyclopedische dumps
* dubbele versies van vrijwel dezelfde documentatie
* irrelevante machine learning bundels voor deze eerste fase

Doel:
Wintrip moet Python-code kunnen lezen, kleine scripts begrijpen, bestandsverwerking snappen en veilige wijzigingen kunnen voorbereiden.
