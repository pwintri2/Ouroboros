# Java PDF Checklist

Plaats hier bij voorkeur 1 hoofdbron en maximaal 1 extra bron.

Aanbevolen type bronnen:

* Java tutorial of compacte Java basisgids
* bron over object-oriented programming in Java

Vermijd:

* zeer formele language specifications als eerste bron
* extreem grote enterprise-framework documenten
* meerdere overlappende beginner-PDF’s zonder extra waarde

Doel:
Wintrip moet Java-basics, classes, methods, exceptions en OOP-structuren kunnen herkennen en toepassen bij code-analyse.
