# PHP PDF Checklist

Plaats hier bij voorkeur 1 hoofdbron en maximaal 1 extra bron.

Aanbevolen type bronnen:

* officiële PHP manual of compacte PHP language guide
* gids over forms, file handling of eenvoudige server-side logica

Vermijd:

* legacy handleidingen die zwaar leunen op verouderde patronen
* extreem grote alles-in-één handboeken
* bronnen zonder praktische codevoorbeelden

Doel:
Wintrip moet basis PHP-code kunnen lezen, eenvoudige web-logica begrijpen en kleine veilige aanpassingen kunnen voorbereiden.
