# WintripAI — ROUND9_PLAN

## Ronde 9: True Streaming, Search Actions & Workflow Depth
**Datum:** 2026-04-12
**Status:** Gepland / gestart

## Doel
Mission Control verder ontwikkelen van een sterke prototype-cockpit naar een meer dagelijkse, werkbare interface met diepere realtime interactie en bruikbare workflow-acties.

## Scope

### 1. Echte token streaming
Doel:
- demo-stream vervangen of dichter benaderen met echte backend/orchestrator output
- partial token updates netter afhandelen
- betere statusweergave tijdens streaming

Werkpunten:
- streaming endpoint(s) uitbreiden
- frontend partial updates verfijnen
- streaming completion en error states

### 2. Search-resultaten bruikbaar maken
Doel:
- semantic hits niet alleen tonen, maar ook inzetbaar maken in de workflow

Werkpunten:
- klik op hit -> voeg toe aan chat/input
- hit-context tonen
- gebruik als geheugen/context voorbereiden

### 3. Chat/session persistence verdiepen
Doel:
- actieve chats consistenter maken als werkcontext
- betere relatie tussen sidebar chat history en actieve workspace

Werkpunten:
- actieve chatflow verfijnen
- berichten beter koppelen aan geselecteerde chat
- UX voor nieuwe/actieve chat verbeteren

### 4. Upload/documentflow verbeteren
Doel:
- duidelijker maken wat er met documenten gebeurt
- brug slaan tussen upload, ingest en retrieval

Werkpunten:
- upload feedback verfijnen
- ingested bestanden duidelijk tonen
- document-context beter zichtbaar maken

### 5. Workflow polish
Doel:
- Mission Control vloeiender en consistenter maken

Werkpunten:
- states voor loading/error/empty aanscherpen
- search/chat/diff coherenter maken
- visuele polish waar nodig

## Verwachte uitkomst
Na Ronde 9 moet WintripAI sterker aanvoelen als:
- realtime werkplek
- bruikbare cockpit voor dagelijkse interactie
- interface waar search, chat en context elkaar echt ondersteunen
